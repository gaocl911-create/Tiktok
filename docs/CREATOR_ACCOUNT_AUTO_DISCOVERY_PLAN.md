# 账号作品自动发现控制方案

## 背景

添加抖音作者账号后，系统原来会在定时采集中自动从作者主页拉取新作品。这个行为容易把与当前业务无关的作品加入监控，尤其是作者账号同时发布多类内容时，误采集风险较高。

## 方案

1. 作者账号新增后，默认不自动发现主页新作品。
2. 后台账号列表提供“自动发现作品”开关。
3. 开启后，SnailJob 定时任务才会从作者主页发现并加入新作品。
4. 关闭后，系统仍会刷新已经建立监控关系的作品指标，但不会自动加入作者主页新作品。
5. 后台账号列表保留“同步作品”按钮，用于人工确认后立即从作者主页同步一次作品。
6. “刷新作者数据”只刷新作者主页资料，不再顺手同步作品。

## 已完成

- 后端复用 `cm_monitor_target.discover_new_content` 作为自动发现开关。
- 新增接口：`PUT /creator/account/{creatorId}/discover-new-content`。
- 账号列表返回 `targetId` 与 `discoverNewContent`。
- 定时采集逻辑已按 `discoverNewContent` 判断是否拉取作者主页作品。
- 新增后台账号列表开关与“同步作品”按钮。
- 作者详情页和抽屉的“刷新作者数据”已改为只刷新作者资料。
- 已将当前数据库中已有的作者账号监控统一关闭自动发现，避免旧数据继续自动拉取主页新作品。

## 使用建议

默认保持关闭。只有当你确认该作者账号发布内容都属于当前业务范围时，再开启自动发现。其他情况建议用“同步作品”人工拉取，再审核是否需要继续监控。
