## 2. 后端密钥

| 项 | 旧值 | 新值要求 | 配置位置 |
|---|---|---|---|
| `SA_TOKEN_JWT_SECRET` | `abcdefghijklmnopqrstuvwxyz` | 64+ 字符随机串 | `deploy/.env.prod` |
| `SNAIL_JOB_TOKEN` | `SJ_cKqBTPzCsWA3VyuCfFoccmuIEGXjr5KT` | 32+ 字符随机串 + 同步更新 `sj_group_config` 表 | `deploy/.env.prod` + DB |
| `API_DECRYPT_REQUEST_PRIVATE_KEY` | yml 中明文 RSA 私钥 | 重新生成 RSA-2048 keypair | `deploy/.env.prod` |
| `API_DECRYPT_RESPONSE_PUBLIC_KEY` | yml 中明文 | 同上 keypair 的公钥 | `deploy/.env.prod` |

生成命令：

```bash
# JWT / Token / 密码通用：
openssl rand -base64 48 | tr -d '\n='

# 接口加解密 RSA keypair（用 PKCS#8 / Base64）：
openssl genrsa -out request-priv.pem 2048
openssl pkcs8 -topk8 -nocrypt -in request-priv.pem -out request-priv-pkcs8.pem
openssl rsa -in request-priv.pem -pubout -out request-pub.pem
# 然后把 -----BEGIN/END-----、换行去掉，整行复制到 env
```

- [ ] sa-token JWT 已轮换（旧 token 全部失效，所有用户需重新登录）
- [ ] SnailJob token 已轮换 + `sj_group_config.token` 同步更新
- [ ] RSA 请求解密 keypair 已重新生成
- [ ] 前端 `web/.env.production` 的 `VITE_APP_RSA_PUBLIC_KEY` 已同步成新公钥
