## 1. 当前阶段目标

先把兼职任务业务闭环做出来，暂时不把精力放在正式域名、上线备案、HTTPS 证书和微信后台合法域名配置上。

第一阶段要跑通这条主线：

```text
后台发布任务
-> 兼职人员小程序登录/入驻
-> 小程序领取任务
-> 兼职人员提交抖音作品链接
-> 后台审核作品
-> 审核通过后自动加入抖音内容监测
-> 后台查看监测数据
-> 后续再做结算
```

这个阶段的核心不是页面数量，而是让“兼职人员提交作品 -> 平台审核 -> 自动监测”的链路真实可用。

## 3. 小程序前端功能规划

### 3.1 P0 必做页面

| 页面 | 作用 |
| --- | --- |
| 登录页 | 微信登录，获取 openid，创建或绑定小程序用户 |

| 任务详情页 | 展示任务要求、佣金、截止时间、提交规则 |

### 3.2 P1 后续页面

- 收益明细。
- 提现申请。
- 消息通知。
- 任务搜索和筛选。
- 作品数据趋势。

### 3.3 小程序建议底部导航

```text
首页 | 任务 | 作品 | 我的
```

其中：

- 首页：展示任务推荐、入驻状态、待处理提醒。
- 任务：任务大厅和任务详情入口。
- 作品：我的提交作品、审核状态、监测状态。
- 我的：个人资料、收益、入驻审核状态。
